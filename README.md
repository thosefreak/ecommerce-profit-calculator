# 跨境电商利润计算器

一个面向小型跨境电商卖家的单件利润测算工具。下载并解压后，双击 `index.html` 即可使用，无需安装软件、注册账号或连接网络。中文界面，适合没有代码基础的使用者。

## 能做什么

- 输入商品售价、手动汇率及人民币成本，立即查看单件预估利润和销售利润率。
- 分别填写平台佣金、支付比例手续费、每单固定手续费及售后预留。
- 查看成本明细、保本售价与目标利润率对应的售价。
- 支持 USD、EUR、GBP、CNY；这些只是计价单位，不带实时汇率。
- 可手动保存到本机浏览器，或导出带中文表头的 CSV 文件。
- 使用原生 HTML、CSS、JavaScript，无安装步骤、外部字体、接口、统计或追踪脚本。

## 第一次使用：约 3 分钟

1. 完整解压 ZIP，不要直接在压缩包预览中打开页面。
2. 用现代浏览器（例如 Edge、Chrome、Firefox 或 Safari）打开 `index.html`。无需运行任何命令。
3. 选择销售币种，填写折扣后的每件售价；汇率方向是 **1 单位销售币种 = 多少人民币**。
4. 将采购、包装、物流仓储、广告及其他支出按每件分摊后填写，全部用人民币。没有的成本填 `0`，不要留空。
5. 按自己的账单填写费率。页面自动更新结果。示例的汇率、售价及费率只是演示，不代表当前行情或任何平台收费标准。
6. 如需保留，点击“保存到本机”或“导出 CSV”。不点击保存的修改只在当前页面有效。

切换销售币种**不会**自动兑换已有售价、固定手续费或汇率；请重新填写核对。选择 CNY 时汇率自动固定为 1。

“载入示例”只更改当前页面；“清空并删除已保存数据”将金额和比例归零、汇率设为 1，并删除本工具在当前浏览器中保存的数据。重要测算先导出再清空。

## 用演示数据核对

打开页面首次显示以下虚构演示数据：

| 项目 | 示例 |
| --- | ---: |
| 售价 | 29.90 USD |
| 汇率 | 1 USD = 7.20 CNY |
| 采购 / 包装 / 物流 / 广告 / 其他 | 55 / 3 / 36 / 12 / 2 CNY |
| 平台佣金 / 支付比例费 / 售后预留 | 15% / 3% / 3% |
| 固定支付手续费 | 0.30 USD |
| 目标利润率 | 20% |

结果应为：收入 **215.28 CNY**，总成本 **155.37 CNY**，单件预估利润 **59.91 CNY**，利润率 **27.83%**，保本售价 **19.37 USD**，20% 目标利润率的售价 **25.94 USD**。

计算使用完整精度，金额展示保留两位小数，所以明细显示值相加可能与总计差 0.01。保本及目标售价向上取整到分，避免普通四舍五入导致略低于目标。

## 计算口径

这是一个**一单一件、卖家包邮**的简化模型。售价为折扣后的、不含代收销售税的商品收入，不另外计算买家支付的运费。

设售价为 P，人民币汇率为 E；人民币成本合计为 C；单笔固定手续费（销售币种）为 F；平台、支付及售后预留的合计比例为 r；目标利润率为 t。百分比先除以 100。

```text
销售收入（CNY）= P × E
人民币成本合计 C = 采购 + 包装 + 物流仓储 + 广告 + 其他
总成本（CNY）= C + F × E + P × E × r
单件预估利润（CNY）= 销售收入 − 总成本
销售利润率 = 单件预估利润 ÷ 销售收入 × 100%
保本售价（销售币种）= (C + F × E) ÷ [E × (1 − r)]
目标售价（销售币种）= (C + F × E) ÷ [E × (1 − r − t)]
```

- 利润率以销售收入为分母，**不是**以采购成本为分母的加价率。
- 售价为 0 时仍可计算成本和亏损，利润率显示“—”，CSV 中写“不适用”。
- 费用及预留的合计比例必须小于 100%。单项比例上限 99.99%。
- 目标利润率与合计比例费用达到或超过 100% 时，目标售价显示“无法达到”，其他结果仍可计算。本工具将此情况视为不适用，不处理零成本下的特殊边界。
- 汇率须为 0.000001 至 1,000,000；金额输入为 0 至 100,000,000。负数、空白和无效输入会提示错误并停止显示结果。
- 售后预留是估算缓冲，不是对退款损失的精确统计。
- 多件订单、最低收费、封顶/阶梯费率、价税分离和复杂退货暂未建模。税费、人工、软件费等仅在你手动分摊并填入后才会计入；请避免重复记账。实际费用以合同、平台账单和真实结算为准。
- 这是经营测算小工具，不是完整会计或税务系统。

## 上传到 GitHub：无需命令行

建议仓库名：`cross-border-profit-calculator`。可复制的仓库简介：

> Offline cross-border e-commerce profit calculator with a Chinese interface, manual exchange rates and CSV export.

1. 登录自己的 GitHub，创建一个空仓库，填写上述名称或你喜欢的名称。公开与否按需要选择。新建时不必额外生成 README、LICENSE 或 .gitignore，本包已经包含。
2. 解压下载的 ZIP，进入 `cross-border-profit-calculator` 文件夹。**上传里面的文件，不要只上传 ZIP，也不要把外层文件夹套在仓库根目录。**
3. 在仓库页面找到文件上传入口（已有文件的仓库通常为 `Add file` → `Upload files`；空仓库也有上传现有文件的入口）。选择本项目全部文件，包含 `.gitignore`。
4. 确认仓库根目录将显示 `index.html`、`README.md`、`LICENSE`、`.gitignore`、`CHANGELOG.md` 和 `CHECKLIST.md`。
5. 写一条符合实际的提交说明，例如“添加离线利润计算器初版”，按页面提示提交。不要填写虚构的历史日期或贡献者。
6. 上传后 README 会作为项目说明展示。GitHub 的普通代码文件页面不会直接运行计算器；本项目的最简使用方式仍是下载后双击 `index.html`。如以后需要在线版本，可以再研究静态网页托管。

GitHub 界面文字可能随语言和页面状态不同。参考：[GitHub 官方文件上传指南](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)。

## 如何做真实、长期的维护

把它当作自己会用的小工具，按实际需要修改，而不是按天数制造提交：

- 第一次用自己的商品核对结果，记录发现的问题；公开记录时用脱敏或虚构样例。
- 有实际需要时修正说明、补充常见问题或改进成本分类。
- 用 GitHub Issues 写清楚“遇到什么问题、希望怎么算”，不要求每天开 Issue。
- 修改后照 `CHECKLIST.md` 手动核对，并把真实完成的改动记入 `CHANGELOG.md`。
- 未来可按需要增加多商品对比、不同平台计费规则或英文界面；未实现前不要宣称支持。

项目不包含刷星、自动空提交、伪造历史贡献或账号验证脚本。正常使用和维护仓库**不保证通过 Telnyx 或其他第三方验证**。

## 隐私与数据保存

页面没有网络请求；计算数据不上传到服务器。只有点击“保存到本机”才写入当前浏览器的 `localStorage`，使用键 `trade-margin:v1`。之后每次打开会尝试读取该份数据。保存不等于加密，也不保证跨浏览器、跨设备或移动文件后仍能读取；浏览器对 `file://` 文件的存储策略有所不同，隐私模式或清理缓存也可能使保存失效。

CSV 含有当次输入及主要结果，请自行妥善保存。CSV 默认下载到浏览器设置的目录，不一定在项目文件夹里。不要把真实成本、客户信息、订单、账号凭证或导出的业务 CSV 上传到公开仓库。`.gitignore` 只是辅助，不会阻止网页手动上传，也不会删除已经提交的文件。
